# Bihar Bloom Experience

Build a world-class, premium cinematic React website for an Indian food brand called “FREZSO”.

FREZSO is a premium food brand ORIGINATED FROM BIHAR, INDIA.

The main product is PREMIUM ROASTED MAKHANA.

The website must combine:

APPLE-STYLE PRODUCT STORYTELLING

+

LUXURY FMCG BRANDING

+

BIHAR HERITAGE

+

MODERN INDIAN DESIGN

+

CINEMATIC SCROLL-DRIVEN ANIMATIONS

The website should feel like a premium brand launch experience, NOT like a normal food/e-commerce website.

====================================================

1. CORE BRAND IDEA

====================================================

Brand:

FREZSO

Origin:

BIHAR, INDIA

“Bihar's iconic Makhana, reimagined for the modern world.”

====================================================

2. DESIGN PHILOSOPHY

====================================================

The website should be inspired by the QUALITY and STORYTELLING STYLE of Apple's product websites.

Do NOT copy Apple's branding, logo or exact design.

Take inspiration from:

- cinematic product reveals

- huge typography

- extreme whitespace

- pinned scrolling sections

- scroll-controlled product movement

- product transformations

- horizontal storytelling

- layered animations

- smooth transitions

- minimal navigation

- premium micro-interactions

The website should feel like a luxury product film that the user controls by scrolling.

CORE PRINCIPLE:

SCROLL = STORY

Every major scroll should reveal something meaningful.

Do NOT simply add:

fade-in

fade-up

slide-in

to every section.

Instead use:

scroll-driven transformation

product scaling

product rotation

parallax

horizontal movement

image masking

text transformation

background transitions

layered objects

pinned sections

cinematic reveals
